System Architecture

◈

Arduino Sensors

DHT11/22 reads temperature and humidity. Capacitive soil sensor returns raw ADC. Data sent over Serial at 9600 baud every 2 seconds.

◎

Relay Pump Control

Python sends PUMP_ON / PUMP_OFF over the same serial connection. Arduino controls the relay pin directly. Auto-triggers on moisture thresholds.

⬡

Random Forest ML

Trained on 20,000 samples across 15 plant profiles. 95%+ accuracy. Predicts health score (0-100), grade (A-F), and identifies root causes.

◐

SQLite Database

All readings persisted. Plant profiles stored and editable. Full assessment history. No external database needed.

⊕

Trend Detection

ML model uses rolling sensor history to detect drying trends, temperature spikes, and humidity drops before they become critical.

◉

Real-time Polling

Browser polls /data every second. DOM updates live — no page reload. Charts refresh automatically with each new Arduino reading.
